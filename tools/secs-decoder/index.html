How to read the result

  

    
An HSMS message is a 4-byte length, a 10-byte header and an optional SECS-II body. The header carries the session ID, the stream and function (S1F13 means stream 1, function 13), the W-bit that asks for a reply, and system bytes that pair a reply with its request.

    
Each SECS-II item starts with a format byte and one to three length bytes. Lists (L) count items; every other format counts bytes. SML writes each item as <format value>, with lists indented.

    
Control messages such as Select and Linktest have no SECS-II body; bytes 2–3 carry status or reason codes instead of stream and function, and the type is in the SType byte.

  





  
Standard

  
Message format: SEMI E5 (SECS-II). Transport over TCP/IP: SEMI E37 (HSMS). The examples use invented values.
