# HYTEK SOLUTIONS VN — website

Static website for HYTEK SOLUTIONS VN COMPANY LIMITED — semiconductor equipment software engineering.

- `index.html`, `styles.css` — page and styles
- `i18n.js` — English / Vietnamese switch (`?lang=vi`)
- `app.js` — 3D process chamber, GEM/SECS exchange, simulations
- `equip.js` — equipment platform simulations

All visuals are simulations. Open `index.html` in a browser to preview; no build step.
